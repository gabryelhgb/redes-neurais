# Redes Neurais

Repositório destinado aos exercícios de redes neurais para estudo de Inteligência Artificial

## Projetos

### 01 - Perceptron com regra de Hebb

Implementação manual de uma rede neural de um único neurônio, treinado de forma supervisionada utilizando a Regra de Hebb.

A rede classifica o perfil de um aluno entre:

- Sistemas de Informação ou Computação
- Humanas

O algoritmo será desenvolvido em Python sem bibliotecas prontas de redes neurais. Quero aprender o funcionamento de uma IA da forma mais pura.
